# Proyecto

Sistema de transferencias bancarias con QR: backend en Spring Boot 4 (Java 25) y frontend en React.

## Reglas

@.claude/rules/springboot.md
@.claude/rules/react.md

## Antes de terminar una tarea

Una tarea no se da por terminada hasta que:

- El backend compila: `./gradlew build` dentro de `backend/`.
- El frontend pasa lint y build: `npm run lint` y `npm run build` dentro de `frontend/`.

Si alguno falla, se corrige antes de cerrar la tarea; si no se pudo ejecutar, se informa explícitamente.
